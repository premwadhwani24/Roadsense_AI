# Contributing to RoadSense AI

Thank you for your interest in contributing to RoadSense AI! We are building the future of smart road infrastructure and welcome all contributions.

## How to Contribute

### 1. Reporting Bugs
- Use the GitHub Issues tracker to report bugs.
- Include steps to reproduce and system details.

### 2. Feature Requests
- Suggest new features or improvements via Issues.
- Provide a clear description and use case.

### 3. Pull Requests
1. Fork the repository.
2. Create a feature branch (`git checkout -b feature/AmazingFeature`).
3. Commit your changes.
4. Push to the branch.
5. Open a Pull Request for review.

## Code Standards
- Follow PEP 8 for Python code.
- Ensure all new features include basic tests.
- Document new API endpoints in the README.

We appreciate your help!
